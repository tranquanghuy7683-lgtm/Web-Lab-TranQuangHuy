# Bài tập Lập trình Web

**Sinh viên:** Trần Quang Huy  
**MSSV:** 25dh110973

## Cách chạy
Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong Visual Studio Code.

## Nội dung
- `Web-Lab01a_HTML`: HTML cơ bản, liên kết, bảng, colspan/rowspan.
- `Web-Lab01b2_HTML`: Dựng layout bằng table, div và HTML5.
- `Web-Lab01c_HTML`: Form đăng nhập, lấy lại mật khẩu, đăng ký.

Các bài được viết theo mức nhập môn, dùng HTML/CSS cơ bản và không dùng JavaScript.
